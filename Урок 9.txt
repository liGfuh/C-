1. Логические операторы - используются для проверки конкретного условия.


2. Короткий цикл вычислений - совокупность нескольких условий которые определяют выводимый результат.


3. Логический оператор И

   false + false = false
   false + true = false
   true + false = false
   true + true = true


4. Логический оператор ИЛИ 

   false + false = false 
   false + true = true 
   true + false = true 
   true + true = false 


5. Логический оператор XOR 

   false + false = false 
   false + true = true
   true + false = true 
   true + true = false
