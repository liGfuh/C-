1. ASCII - это американский стандарт код для обмена информацией, который определяет способ представления символов.


2. Управляющие символы - это символы начинающиеся на \ выполняющие модификационные действия над выводом потока.


3. При работе с управляющими символами и функциями надо обращать внимание на особенности обработки буффера потока ввода и вывода. 


4. Буфер - временное хранилище данных, которое помогает сгладить разницу в скорости между источником данных и их получателем. 


5. Тип wchar_t -> следует избегать во всех случаях кроме тех которые связаны с Windows API/


6. Существуют следующие кодировки Unicode:

   UTF-32 - требует 32 бита для представления символа.
   UTF-16 - требует 16 бит для представления символа.
   UTF-8 - требует 8 бит для представления символа.


7. Литеральные константы - значения, которые вставляются непосредственно в код поскольку они являются константами, то их значение нельзя изменить.


8. Суффиксы типов данных - определённый набор символов который помогает компилятору определить какой тип литеральной константы должен быть введён для инициализации идентификатора с некоторым типом данных.


9. Таблица Суффиксов:

   int	                  u или U                       unsigned int
   
   int	                  l или L	                long

   int	      ul, uL, Ul, UL, lu, lU, Lu или LU	        unsigned long

   int	                 ll или LL	                long long

   int	   ull, uLL, Ull, ULL, llu, llU, LLu или LLU	unsigned long long

   double	         f или F	                float

   double	         l или L	                long double
 


10. При работе с суффиксами и литерами для объявления переменных следует следить на каких стандартах они работают.


11. Магическое число - это хорошо закодированный литерал в строке кода, который не имеет никакого контекста.


12. Константа - ключевое слово перед типом переменной или после него.


13. Время компиляции - когда ты находишься в процессе компиляции программы.


14. Время выполнения программы - временной промежуток с момента старта выполнения программы и до момента окончания её работы.


15. Константы времени выполнения - их значения определяются только во времени выполнении программы.


16. Константы времени компиляции - их значения определяются во время компиляции программы.


17. Символьные констант - это тот же литерал, только с идентификатором. (Было в уроке про макросы - Макрос текст_замена).
