1. Конфликт имён - возникает, когда два одинаковых идентификатора находятся в одной области видимости и компилятор не может понять, какой из этих двух следует использовать в конкретной ситуации.


2. Пространство имён с одинаковыми названиями - допускается объявление пространств имён в нескольких местах. Всё, что находится внутри одного блока имён, считается частью только этого блока. 


3. Псевдонимы и вложенные пространства имён - одни пространства имён могут быть вложены в другие пространства имён.


4. Пространство имён - определяет область кода, в которой гарантируется уникальность всех идентификаторов. 


5. Объявление пространства имени - локальное объявление пространства имени.


6. Объявление директивы пространства имени - глобальное объявление пространства имени.


7. Неявное преобразование типов - когда компилятор автоматически конвертирует один фундаментальный тип данных в другой.


8. Явное преобразование типов - когда разработчик использует один из операторов явного преобразования для выполнения конвертации объекта из одного типа данных в другой.


10. Числовое расширение - когда значение одного типа данных конвертируется в другой тип данных побольше.


11. Интегральное расширение - включает в себя преобразование целочисленный типов, меньших, чем int(bool, char, unsigned char, signed char, unsigned short, signed short) в int(если это возможно) или unsigned int.


12. Расширение типа с плавающей точкой -  конвертация из типа float в тип double.


13. Числовая конверсия - когда мы конвертируем значение из более крупного типа данных в аналогичный, но более мелкий тип данных.


14. При обработке выражений компилятор разбивает каждое выражение на отдельные подвыражения. Арифметические операторы требуют, чтобы их операнды были одного типа данных. Чтобы это гарантировать, компилятор использует следующие правила:

#1 Если операндом является целое число меньше (по размеру/диапазону) типа int, то оно подвергается интегральному расширению в int или в unsigned int.

#2 Если операнды разных типов данных, то компилятор вычисляет операнд с наивысшим приоритетом и неявно конвертирует тип другого операнда в такой же тип, как у первого.

 Приоритет типов операндов:

       double
       float 
       unsigned long long 
       long long 
       unsigned long 
       long 
       unsigned int
       int
