1. Бит - наименьшее единица памяти, имеет всего два значения, 1 и 0.


2. Адрес - номер какого-либо объекта памяти.


3. Байт - наименьшая единица памяти имеющая свой адрес. 8 бит = 1 байт


4. Тип данных - та или иная форма последовательности бит или же байтов. 


5. Основные типы данных:

   Логический тип данных    - bool               - true или false  - 1 байт 

   Целочисленный тип данных - short              - Число из Z      - 2 байт
                            - int                - Число из Z      - 4 байт 
                            - long long          - Число из Z      - 8 байт
                            - long               - Число из Z      - 4 байт 
                  Модификатор (unsigned)         - делает число строго из N + 0
                  Модификатор (signed)           - стоит по умолчанию, определяет наличие - части и + части
   Модификатор строго для целых чисел "u" - писать как постфикс - из-за него будет автоматически писаться unsigned
   
   Вещественные типы данных - float              - Число из R      - 4 байт
                            - double             - Число из R      - 8 байт
                            - long double        - Число из R      - 16 байт
   
   Символьный тип данных    - char               - буква из ASCII  - 1 байт
                            - void               -                 - пустота
                            - wchar_t            - широкие символы - 2 байт 
                            - char16_t           - буква из UTF-16 - 2 байт 
                            - char32_t           - буква из UTF-32 - 4 байт


6. Объявление переменной - выделение памяти под идентификатор путём определения типа данных которые будут хранится под ним.


7. Инициализация переменной - присваивание значение объявленной переменной.


8. Копирующая инициализация - присваивание значение объявленной переменной через знак '='.


9. Прямая инициализация - присваивание значение объявленной переменной через {} или ().


10. Переполнение - потеря бит из-за того, что переменная не было выделено достаточно памяти для хранения. 


11. Экспоненциальная запись - мантисса x 10^экспонент.


12. По умолчанию используется стандарт IEEE 754.


13. Ошибка округления - получение математического артефакта которого не было в начальной инициализации.


14. Манипулятор потока - это специальная функция или объект, который применяется к потокам ввода-вывода который изменяет форму данных.


15. Модификатор - ключевое слово меняющее свойство объекта.
