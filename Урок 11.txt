1. Побитовые операции - это битовая операция в программировании, которая работает с целыми числами на уровне их двоичных разрядов, сравнивая или изменяя каждый отдельный бит.


2. Побитовый сдвиг влево << и вправо >>

  3 <=> 0011
  3 << 1 <=> 0110 = 6
  3 << 2 <=> 1100 = 12
  3 >> 1 <=> 0001 = 1
  3 >> 2 <=> 0000 = 0


3. Побитовый оператор НЕ ~

  4 <=> 0100

  ~4 = 1011 <=> 11

4. Побитовый оператор И 

  
   5 & 6 

   0 1 0 1 // 5
   0 1 1 0 // 6
   ============
   0 1 0 0 // 4


5. Побитовый оператор ИЛИ 

   
   1 | 4 | 6

   0 0 0 1 // 1
   0 1 0 0 // 4
   0 1 1 0 // 6
   ============
   0 1 1 1 // 7


6. Побитовое исключающее XOR 

   
  6 ^ 3
  
  0 1 1 0 // 6
  0 0 1 1 // 3
  ============
  0 1 0 1 // 5


7. Побитовые операторы присваивания 

   Присваивание с побитовым сдвигом влево:                <<=   (x <<= y) Присваиваем результат [x << y] - x
   Присваивание с побитовым сдвигом вправо:               >>=   (x >>= y) Присваиваем результат [x >> y] - x
   Присваивание с побитовой операцией ИЛИ:                |=    (x |= y)  Присваиваем результат [x |= y] - x
   Присваивание с побитовой операцией И:                  &=    (x &= y)  Присваиваем результат [x &= y] - x
   Присваивание с побитовой операцией исключающей ИЛИ:    ^=    (x ^= y)  Присваиваем результат [x ^= y] - x


8.  И   - Конъюнкция                   A * B
    ИЛИ - Дизъюнкция                   A + B
    XOR - Сложение по модулю           A ⨁ B
    NOT - Инверсия      ~x             -x - 1
    <<  - Умножение на степень двойки  A * 2^n
    >>  - Деление на степень двойки    A / 2^n


9. Битовые флаги - это компактный способ хранения нескольких логических значений в одной переменной.
